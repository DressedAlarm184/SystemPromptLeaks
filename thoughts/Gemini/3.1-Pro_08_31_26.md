Here is the breakdown of the difference:

### **Kleki** (The App)

Kleki (kleki.com) is the **consumer-facing, hosted web application**.

* **Target Audience:** Artists, hobbyists, and anyone who wants to open a browser and start drawing immediately.
* **Functionality:** It is the official, branded instance of the painting tool. You don't need to install, compile, or host anything. You just go to the website and use the layers, brushes, and WebGL-powered filters.

### **Klecks** (The Code)

Klecks is the **open-source underlying engine and source code** that powers Kleki.

* **Target Audience:** Developers, coders, and website owners.
* **Functionality:** It is available on GitHub (maintained by the creator, bitbof). Developers use Klecks to embed the painting app into their own websites, run it locally as a standalone tool, or integrate it into things like Oekaki boards.

### **The Bottom Line**

If you are sitting down to draw a picture, you are using the same brushes and UI regardless of the name. However, **Klecks** occasionally receives new, experimental features in its codebase before they are officially deployed to the live **Kleki** web app.

If you just want to draw, use **Kleki**. If you want to host your own drawing app, contribute to the source code, or embed a canvas in your own project, use **Klecks**.
